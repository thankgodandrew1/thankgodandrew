# 🚀 What I'm Building

## 🛍️ Broda

**A premium contemporary African fashion digital platform.**

Broda is my exploration of what happens when an e-commerce application is treated as a **real product and software system**, rather than simply a storefront.

The project includes a dedicated Python backend and Next.js frontend, shared packages, documentation, deployment infrastructure, automated testing, development tooling, and an explicit engineering implementation plan.

### Engineering focus

* Modular backend architecture
* Customer identity and access
* Product experience
* Shopping experience
* Cart and wishlist
* Promotions
* Checkout architecture
* Secure browser sessions
* Automated testing
* Documentation-driven development
* Docker-based development
* Architecture decision records

**Stack**

`Python` · `FastAPI` · `Next.js` · `TypeScript` · `PostgreSQL` · `Docker`

The project currently stops deliberately at the payment boundary rather than pretending to implement functionality that does not yet exist.

# 🧠 MOMS

### Mission Operations Management System

MOMS is an attempt to design a **complete operational management platform** around a complex organization.

Rather than beginning with screens, the project explores:

* Domain modeling
* Business rules
* System architecture
* Personnel
* Organizational structure
* Activities
* Resources
* Meetings
* Knowledge management
* Reporting
* Notifications
* Operational intelligence
* Administration

The project is being developed as a **modular monolith**, with architecture and implementation treated as first-class parts of the product.

The repository currently contains the MOMS system alongside project scaffolding and development configuration, reflecting an ongoing transition from system design into implementation.

### Why I'm building it

Many organizations still operate through a combination of:

`Spreadsheets + PDFs + Email + WhatsApp + Memory + Manual Follow-up`

MOMS explores what happens when those processes are instead represented as **one coherent operational system**.

→ **[Explore MOMS](https://github.com/thankgodandrew1/moms)**
